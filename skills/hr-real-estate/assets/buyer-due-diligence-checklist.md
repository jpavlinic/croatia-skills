# Provjera nekretnine prije kupnje / Buyer due-diligence checklist

Nekretnina / Property: ____________________ (k.o. ________, k.č. ________, ZK uložak ________, poduložak/etaža ________)
Prodavatelj / Seller: ____________________ (OIB ________)
Kupac / Buyer: ____________________ (OIB ________, državljanstvo / nationality ________)
Datum provjere / Date checked: ________

## 1. Zemljišna knjiga i katastar / Land register and cadastre

- [ ] ZK izvadak od danas (oss.uredjenazemlja.hr) / Current land-register extract
- [ ] Prodavatelj upisan u B listu, udjeli ukupno 1/1 / Seller registered in list B, shares 1/1
- [ ] C list: tereti popisani i dogovoreno brisanje / List C encumbrances listed, deletion agreed: ________
- [ ] Nema plombe ni zabilježbe spora ili ovrhe / No plomba, no lawsuit or enforcement note
- [ ] Stan etažiran (poseban dio) / Flat registered as a separate unit
- [ ] Katastar odgovara ZK-u i stanju na terenu / Cadastre matches the register and reality
- [ ] Lanac vlasništva uredan (ostavinsko rješenje upisano) / Chain of title registered
- [ ] Suglasnost bračnog druga ili partnera, ako je potrebna / Spouse/partner consent if needed
- [ ] Punomoći ovjerene i ne starije od godine dana (opća punomoć) / Powers of attorney certified, general ones ≤ 1 year

## 2. Zgrada i dozvole / Building and permits

- [ ] Uporabna dozvola / rješenje o izvedenom stanju / zgrada izgrađena prije 15. 2. 1968. (dokaz): ________
- [ ] Nema nelegalnih dogradnji (zatvoreni balkon, potkrovlje, dodatna etaža) / No illegal extensions
- [ ] Energetski certifikat predočen; razred: ____ ; vrijedi do: ____ / Energy certificate shown
- [ ] Zemljište: namjena prema prostornom planu, pristupni put, priključci / Land: zoning, access, utilities
- [ ] Poljoprivredno zemljište: ponuda ministarstvu (pravo prvokupa), ako je primjenjivo / Agricultural land: state pre-emption offer

## 3. Stambena zgrada / Apartment building

- [ ] Potvrda upravitelja da nema dugovanja za pričuvu i režije / Manager's no-arrears certificate
- [ ] Iznos pričuve: ____ €/m² ; planirani radovi, krediti zgrade / Reserve amount, planned works, building loans
- [ ] Međuvlasnički ugovor i kućni red / Co-owners' agreement and house rules
- [ ] Suglasnost suvlasnika za kratkoročni najam (ako je planiran) / Co-owner consent for short-term rental (if planned)

## 4. Novac i ugovor / Money and contract

- [ ] Financiranje: odobrenje banke (DSTI ≤ 45 %, LTV ≤ 90 %) / Bank pre-approval
- [ ] Troškovi: porez na promet 3 % ili PDV u cijeni, posrednik, javni bilježnik, odvjetnik, pristojbe / Costs budgeted
- [ ] Predugovor: točni ZK podaci, cijena, rok, kapara ili predujam, uvjeti / Pre-contract terms
- [ ] Kupoprodajni ugovor: clausula intabulandi ili zasebna tabularna isprava kod javnog bilježnika / Registration consent secured
- [ ] Jamstvo za pravne nedostatke, rok primopredaje, tko plaća porez / Warranties, handover, tax
- [ ] Plaćanje tek nakon provjere ZK-a na dan isplate i osiguranog upisa / Pay only after same-day check and secured filing
- [ ] Prijedlog za uknjižbu podnesen u roku od 60 dana / Registration filed within 60 days
- [ ] Rješenje o porezu na promet plaćeno u roku od 15 dana / RETT paid within 15 days
- [ ] Povrat poreza za prvu nekretninu (hrvatski državljani do 45 godina) – zahtjev u roku od 24 mjeseca / First-home refund applied for

## 5. Strani kupci / Foreign buyers

- [ ] OIB / Croatian tax number
- [ ] EU/EGP ili treća država; provjerena uzajamnost / EU/EEA or third country; reciprocity checked
- [ ] Rok za suglasnost ministarstva uključen u ugovor / Ministry consent deadline in the contract
- [ ] Sudski tumač pri potpisu, ako je potreban / Court interpreter at signing if needed

## 6. Nakon primopredaje / After handover

- [ ] Zapisnik o primopredaji sa stanjem brojila / Handover record with meter readings
- [ ] Prijenos režija; obavijest predstavniku suvlasnika u roku od 30 dana / Utilities; notify building representative within 30 days
- [ ] Porez na nekretnine: prijava promjene do 31. ožujka / Property tax: report change by 31 March
